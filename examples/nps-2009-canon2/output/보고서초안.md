## 5. 분석 방법

1. 증거 폴더의 모든 파일을 읽기 전용으로 열어 MD5·SHA-1·SHA-256을 계산했다.
2. E01 이미지는 파일 구조를 직접 해석해 획득 기록값을 읽고, 압축을 풀어 미디어 전체 해시를 다시 계산해 이미지에 저장된 해시와 대조했다.
3. 제공된 참조 해시 목록의 항목을 파일 경로·파일명으로 증거와 짝지어 같은 알고리즘의 해시를 대조했다. 원시 이미지(.raw/.dd 등) 항목은 이름이 같은 E01의 미디어 해시와 대조했다.
4. 확장자와 파일 시그니처 대조, 정확 중복, 이미지 EXIF·유사도, 압축 파일 내부, PDF 구조, SQLite 구조, 개인정보 패턴, 영상·오디오 상태를 자동 점검했다(도구가 없는 항목은 미수행으로 표시).
5. 파일 수정 시각·EXIF 촬영 시각·이미지 획득 기록을 모아 타임라인을 만들었다.
6. 분석을 마친 뒤 모든 파일을 다시 해시해 분석 전 값과 대조했다.
7. 이 초안을 `verify_report.py`로 검사해 근거 없는 해시와 과단정 표현이 없는지 확인했다.
