# 기관 보고서 양식 사용법

빈 HWPX 또는 DOCX에 자리표시자를 넣으면 `lazyforensic report`가 기관의 제목과 절 순서를 따라 같은 형식의 초안을 만든다. 제공된 양식에는 제목이 ‘감정서 (초안)’로 들어 있다. ‘분석보고서’ 등 필요한 제목으로 바꿔도 된다. [한글 빈 양식](../templates/report_form.hwpx) · [Word 빈 양식](../templates/report_form.docx)

## 양식 연결

1. 기관의 빈 양식을 복사하고 고정 제목, 문단, 페이지 설정을 배치한다. 이전 사건의 기재 내용이나 예시 수치가 있으면 지운다. 고정 문구는 출력에도 그대로 실린다.
2. 아래 표에서 필요한 자리표시자를 골라 넣는다. 일반 값은 문장 안이나 기존 표 셀에 여러 번 넣을 수 있다. 새 표를 넣을 곳에는 표 자리표시자 하나를 독립된 문단으로 입력한다. 한글에서 기존 표의 행을 반복하는 방법은 아래 예를 따른다.
3. 증거 폴더와 별도인 출력 폴더를 지정한다. 사건 정보를 함께 넣으려면 `--case-template`으로 입력 파일을 만들고 값을 적는다.

```sh
lazyforensic report --case-template 사건정보.txt
lazyforensic report 증거폴더 -o 결과 --case-info 사건정보.txt --template templates/report_form.hwpx
```

실제 양식을 받으면 마지막 인수만 해당 HWPX 또는 DOCX 경로로 교체한다. 경로에 공백이 있으면 따옴표로 감싼다. 참조 해시 목록은 기존 `--hashes`로 함께 지정한다.

## 자리표시자 목록

| 자리표시자 | 값의 출처와 의미 |
| --- | --- |
| `{{사건번호}}` | 사건 정보 파일의 사건번호 |
| `{{사건명}}` | 사건 정보 파일의 사건명 |
| `{{의뢰인}}` | 사건 정보 파일의 의뢰인 또는 의뢰기관 |
| `{{의뢰일자}}` | 사건 정보 파일의 의뢰일자 |
| `{{분석목적}}` | 사건 정보 파일의 분석 목적 |
| `{{분석담당}}` | 사건 정보 파일의 분석 담당 또는 분석관 |
| `{{작성기관}}` | 사건 정보 파일의 작성 기관 |
| `{{분석관의견}}` | 항상 ‘미확인’. 분석관이 원자료를 검토한 뒤 편집본에 직접 작성 |
| `{{증거목록표}}` | 분석 전 파일별 상대 경로, 바이트 수, MD5·SHA-1·SHA-256 실측값. 읽기 실패한 파일의 크기와 해시는 ‘미확인’ |
| `{{무결성검증표}}` | 기본 초안과 같은 검증 항목·결과·근거. 분석 전후 재해시, 이미지가 있으면 EWF 저장 해시 대조, 참조 해시 대조, 쓰기 방지 장치 사용 및 인계 기록 |
| `{{타임라인표}}` | 시간순으로 정렬한 기록 시각, 출처, 파일, 설명. 파일 수정 시각은 KST, EWF 획득 시각은 UTC, EXIF 원본 시각은 시간대 미기록 |

사건 정보는 입력자가 제공한 값이다. 빈 값, 등록되지 않은 이름, 대조할 자료가 없는 항목은 ‘미확인’으로 표시한다. 증거 목록과 타임라인은 각각 처음 100건까지 싣고, 생략분이 있으면 남은 건수와 전체 목록 파일을 마지막 행에 표시한다. 전체 기록은 `파일해시목록.csv`와 `events.json`에서 확인한다.

## 한글 양식에서 기존 표 행 반복하기

증거 목록을 기관 표의 열 너비와 글자 서식에 맞추려면 머리행 아래에 데이터 행 하나를 만든다. 다음 예처럼 한 셀에 표 자리표시자 전체를 입력하고, 나머지 데이터 셀에는 빈 문단을 하나씩 둔다.

| 파일명 | 크기(바이트) | 해시값 |
| --- | --- | --- |
| `{{증거목록표}}` |  |  |

파일마다 이 행을 복사해 왼쪽부터 파일명, 크기, 해시를 채운다. 머리행이나 뒤의 고정 행은 한 번만 표시한다. 무결성 표도 3열이고 타임라인은 시각, 출처, 파일, 설명의 4열이다. 데이터 칸이 하나뿐이면 그 칸에 열 값을 ` / `로 이어 쓴다. 증거나 타임라인 항목이 비어 있으면 자리표시자에 ‘미확인’이 남는다. 반복 행에서 시작하는 세로 병합은 해제한다. 표 안의 표에도 같은 규칙이 적용된다.

## 검증 결과 읽기

`초안검증.json`의 `template` 항목에 양식 초안의 판정과 사유가 기록된다. 빈 양식의 문단과 표에 실제 입력값을 대입해 예상 본문 SHA-256을 구한다. 저장된 양식 초안에서 문단과 표 행을 다시 읽어 대조하므로, 올바른 해시라도 행이 사라지거나 값의 위치가 바뀌면 실패한다. 본문과 머리말·꼬리말 등에 금지 문구, 근거 없는 해시, 남은 자리표시자가 있어도 실패한다. 양식 초안 검증 실패는 전체 판정 FAIL 및 종료 코드 1로 반영된다.

출력 폴더의 양식 초안과 대조 파일, `무결성검증.json`을 함께 보관한다. 한글은 `양식초안.hwpx.본문.sha256`, Word는 `양식초안.본문.sha256`을 사용하므로 같은 폴더에 두 형식을 보관할 수 있다. 저장한 원본의 본문은 다음 명령으로 다시 확인할 수 있다.

```sh
python scripts/verify_report.py 결과/양식초안.hwpx --evidence 결과/무결성검증.json --json
```

파일 이름을 바꾼 경우 `--template-digest` 뒤에 해당 형식의 원래 대조 파일 경로를 지정한다. 기본 초안과 근거 파일도 같은 출력 폴더에 생성된다. `--no-hwpx`와 `--no-docx`는 각각 기본 초안 생성을 생략한다. `--template`으로 요청한 양식 초안은 생성한다.

## 지원 범위

- 일반 Word DOCX의 본문, 기존 표 셀, 머리말·꼬리말, 각주·미주·메모의 일반 문단에서 글자 자리표시자를 처리한다. 한 문단 안에서 글자 서식이 달라져 여러 런(run)으로 나뉜 자리표시자도 처리한다. 치환값은 첫 글자의 서식을 따른다.
- Word 양식의 표 자리표시자는 본문 표나 머리말 안에 중첩할 수 없다. 일반 텍스트로 입력하고 중간에 탭, 강제 줄바꿈, 필드 코드, 도형을 넣지 않는다. 삽입 표에는 기본 초안의 A4 표 서식이 적용된다.
- 도형 텍스트, 포함 개체, 외부에서 불러오는 본문과 암호화된 양식은 지원 범위 밖이다. 이미지와 그림 속 글자는 판독하지 않는다. 양식 패키지는 압축 해제 기준 64 MiB, 본문 등 개별 XML은 32 MiB까지 지원한다.
- 대조 대상은 문단과 셀의 내용이다. 페이지 나눔, 이미지 및 인쇄 모양은 문서 편집기에서 확인한다. 기관의 고정 문구와 사용자가 입력한 사건 정보의 사실성은 담당자가 확인한다. 대조 파일은 검증 당시 값을 담으므로 초안과 독립적으로 보관하면 이후 편집을 확인할 수 있다.
- 한글 양식에서는 섹션 순서대로 문단, 머리말·꼬리말, 중첩 표를 읽는다. 한 자리표시자 안에서 글자 속성이 바뀌어도 첫 글자 위치에 값을 넣는다. 이미지, 스타일 정의, 패키지 목록은 원본 그대로 복사한다. 기존 텍스트 미리보기는 결과 본문으로 갱신한다.
- 긴 해시의 줄바꿈, 반복 행의 쪽 나눔, 이미지 배치와 인쇄 결과는 한글에서 초안을 열어 확인한다. 바이너리 `.hwp` 입력은 지원 범위 밖이다.

Word 양식 검증은 콘텐츠 형식에 선언된 머리말·꼬리말·각주·미주·메모와 그림 대체 텍스트를 검사한다. 일반 콘텐츠 컨트롤로 감싼 표 셀도 대조한다. 숨김 글자, 변경 추적 삭제문, 텍스트 상자, 데이터 바인딩 및 쪽 번호 이외의 동적 필드는 검증 오류가 된다. 해당 값은 양식에서 일반 문단이나 표 셀에 넣는다.

한글 텍스트 미리보기는 고정 본문만 있는 양식에서도 다시 작성하며 재검증할 때 본문과 대조한다. 그림 설명도 금지 문구와 자리표시자 검사에 포함한다. 동적 한글 필드는 양식 채우기 전에 일반 텍스트로 바꾼다.

압축 항목은 최대 10,000개다. XML은 복사되는 부속 파트도 확인하며, DTD가 있거나 깊이 128단계 또는 요소 250,000개를 초과하면 거부한다. 패키지에는 상대 경로를 사용하며 상위 디렉터리 경로, 역슬래시, 심볼릭 링크, 대소문자·유니코드 정규화 후 중복되는 경로는 허용하지 않는다.
