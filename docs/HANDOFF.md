# v1.1.0 인계 메모 (센터 동료 첫 실행용)

목표: 센터 동료가 자기 PC에서 실제 사건 하나를 돌려 한국어 보고서 초안을 받는 것.
이 메모는 그 실행 직전까지의 상태와, 동료 실행 때 볼 점을 한 장에 정리한다.

## 동료에게 보낼 안내 (그대로 복사)

1. PowerShell을 열고 한 줄 실행 (관리자 권한 필요 없음):
   `irm https://raw.githubusercontent.com/daeryundf2-prog/lazyforensic/main/install.ps1 | iex`
2. PowerShell 창을 새로 열고 실행: `lazyforensic report D:\사건\증거폴더`
   - 사건 정보를 채우려면 먼저 `lazyforensic report --case-template 사건정보.txt`로 양식을 만들고
     값을 적은 뒤 `--case-info 사건정보.txt`를 붙인다.
   - 획득 로그나 해시표가 있으면 `--hashes 해시목록.txt`를 붙인다.
3. 증거 폴더 옆 `증거폴더_분석결과\보고서초안.html`을 브라우저로 연다.

자세한 설명: [`docs/QUICKSTART.md`](QUICKSTART.md). 인터넷 없는 분석 PC는 같은 문서의 "오프라인 설치".

## 초안에서 꼭 볼 것

- **3장 무결성 검증**: 모든 행이 "일치"인지. 화면 마지막에 `확인 필요:`가 나오면 불일치나 판독 오류가 있다.
- **1장·4장의 "미확인"**: 사건 정보·쓰기 방지 장치·인계 기록은 도구가 모른다. 사람이 채운다.
- **4장 획득 환경**: E01에 적힌 기록값(획득 도구·일시)이 실제 획득 기록과 맞는지.
- **6장**: 시그니처 불일치·중복·EXIF·개인정보 패턴은 검토 대상 목록일 뿐이다.
- **7장 분석관 의견**: 비어 있다. 분석관이 쓴다.

## 동료 실행 후 받아 올 피드백

1. 설치 한 줄이 그대로 끝났는지 (Windows 버전, 회사 보안 정책으로 막힌 단계가 있었는지)
2. 증거 폴더 크기·파일 수와 걸린 시간
3. 센터 보고서 서식과 다른 점 (목차 순서, 제목, 필요한 칸, DOCX/HWP 필요 여부)
4. 초안에서 틀렸거나 빠진 값 — 사건 내용은 빼고 항목 이름만

## 알려진 공백 (전체: [`docs/GAPS.md`](GAPS.md))

- 보고서 서식은 일반적인 분석 보고서 구성을 따른 기본안이다. 센터 공식 서식과 맞춰 본 적 없다.
- 출력은 HTML/Markdown뿐이다. DOCX·HWP 파일은 만들지 않는다(HTML을 복사해 붙여 넣기).
- 삭제 파일 복구·카빙·파일시스템 해석·메신저 DB 분석은 하지 않는다. 폴더에 있는 파일과 E01 해시만 본다.
- E01은 libewf가 만든 이미지로만 시험했다. FTK Imager·EnCase가 만든 E01은 동료 실행이 첫 시험이 된다
  ("미지원"이나 "판독 오류"가 나오면 알려 달라).
- Windows 설치·실행은 CI(Windows PowerShell 5.1)로만 확인한다. 실제 센터 PC에서는 아직 돌려 보지 않았다.
- 파일 수정 시각은 복사·내보내기에서 바뀔 수 있다. 원래 시각은 획득 도구나 파일시스템 분석으로 확인해야 한다.
