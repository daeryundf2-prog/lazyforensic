# dlp-leakage-detector: 유출 교차분석 체크리스트

스크립트가 없다. 분석관이 이미 확보한 DLP Excel/CSV, 브라우저 히스토리, USB 연결 기록을 표로 맞출 때 쓰는 절차 메모다.

자동으로 유출을 탐지하거나 민형사 쟁점을 결론내지 않는다.

## 정리 축

1. 검색/준비 — 검색어, 웹하드, 개인 메일 접속 (로그가 있을 때만)
2. 수집/압축 — 대량 다운로드, 암호 zip (파일시스템 증거가 있을 때만)
3. 반출 — DLP 이벤트, USB 시리얼, 클라우드 업로드 (해당 로그가 있을 때만)
4. 정리 — 휴지통, 로그 삭제 도구 실행 흔적 (해당 아티팩트가 있을 때만)

없는 로그를 채워 넣지 않는다. "유출 확정" 문장을 쓰지 않는다.

## 계약

| 항목 | 내용 |
|---|---|
| Intent | 이미 확보한 DLP/웹/USB 로그를 표로 맞추는 절차를 안내한다. |
| Scope | 스크립트 없음. 있는 로그만 정리하고 없는 로그를 채우지 않는다. |
| Evidence | 분석관이 가져온 로그 행. 표의 각 칸은 원본 행에 연결된다. |
| Stop | 정리 표를 내면 끝. "유출 확정" 문장은 쓰지 않는다. |

### 활성화 예시

- 긍정: "DLP 엑셀이랑 USB 기록 표로 맞춰줘"
- 부정: "로그 없이 유출 경로 추정해줘"
- 경계: "로그 일부만 있어" → 있는 축만 채우고 나머지는 비워 둔다
